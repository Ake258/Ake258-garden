> [!quote] 龈下刮治术（subgingival scaling）
> 是==用比较精细的龈下刮治器刮除位于牙周袋内根面上的牙石和菌斑==。研究证明龈下牙石的一部分可能嵌入表层牙骨质内，加之牙周袋内菌斑产生的内毒素可为牙骨质表层所吸收。
> ==🟢龈下刮治术==着重于去除袋内细菌、消除 [[牙龈炎症]]，控制附着丧失的进展。

> [!quote] 根面平整术（root planing）
> 因此，==在做龈下刮治时，必须同时刮除牙根表面感染的病变牙骨质，并使部分嵌入牙骨质的牙石和毒素也能得以清除，使刮治后的根面光滑而平整==（具有生物相容性，有利于牙周组织附着和新生），称为==🟢根面平整术==（root planing）
> ==🟢根面平整术==着重于用器具去除“软化的”牙骨质，使之“变硬、变光滑”

龈下刮治术和根面平整术虽从概念上有所差异，是两个步骤，但在临床上很难区分，实际是**同时进行**的。

## 手用器械龈下刮治（根面平整）

### 常用的龈下刮治手用器械

#### 匙形刮治器

==🟢匙形刮治器（curettes）==是==龈下刮治的主要工具==，其工作端薄而窄，前端为圆形。工作端略呈弧形，其两个侧边均为刃口，可紧贴根面，工作端的横断面呈半圆形或新月形，==操作时只有靠近前端的 1/3 与根面紧贴==。用于前后牙的匙形器外形一致，只是==在器械的颈部形成不同角度==，以利不同牙位的工作，通常成对。
- 此类刮治器统称为“==🟢通用性刮治器==”，这是与==🟢区域专用型刮治器==（以设计者命名的 ==🟢Gracey 刮治器==）的不同之处。Gracey 刮治器是针对不同牙齿、牙面的形状而设计的，它虽然也为匙形，但其外形结构及角度均不同于上述常规的通用型刮治器，两者的区别见表：

|                 | 应用区域                         | 切刃角度                   | 切刃缘的应用                                     |
| --------------- | ---------------------------- | ---------------------- | ------------------------------------------ |
| Gracey 刮治器（专用型） | 有牙位特异性，每支有特殊形态设计，适用于不同牙的不同牙面 | **偏位刃缘**，刃面与器械颈部成 70° 角 | 工作端的两个刃缘不平行，成弯形。==仅应用单侧切刃缘，长而凸的外侧切刃缘为工作缘== |
| 通用型刮治器          | 有前后牙之分，但每支适用于改牙的各个面          | 非偏位刃缘，刃面与器械颈部成 90° 角    | 两侧切刃缘平行而直，==均为工作缘==。                       |

| Gracey 刮治器编号   | 使用范围           |
| -------------- | -------------- |
| 1/2 、3/4       | 前牙             |
| ==🔵5/6==      | ==前牙及尖牙==      |
| ==🔵7/8==、9/10 | 磨牙及前磨牙的==颊舌面== |
| ==🔵11/12==    | 磨牙和前磨牙的==近中面== |
| ==🔵13/14==    | 磨牙和前磨牙的==远中面== |
| 15/16          | 后牙的==近中面==     |
| 17/18          | 后牙的==远中面==     |

> 注：Gracey 刮治器共有 9 支，编号为 1~18，均为双头、成对；一般常用 4 支，即 ==🔵Gracey 5/6、7/8、11/12、13/14==，基本可满足全口各区域的需要。

#### 其它龈下刮治器

1. ==🟢龈下锄形刮治器==（hoe）：器械与牙面应成**两点接触**
2. ==🟢根面挫==（files）：现已少用

### 手用器械龈下刮治的操作要点

1. 龈下刮治是在 [[牙周袋]] 内操作，肉眼不能直视，故==术前应先探明牙周袋的形态和深度、龈下牙石的量和部位==，查明情况后方能刮治。且应选用锐利的龈下刮治器，以提高效率。
2. 同 [[02Area/Notes/龈上洁治术|洁治术]] 一样，以改良握笔式手持器械，稳妥的支点，刮的动作幅度要小，避免滑脱或损伤软组织。每刮以下应与前一下有所重叠，以免遗漏牙石。
3. 用匙形器刮治时，首先要根据治疗牙位选用适当的刮匙。若用 Gracey 刮治器，应认清工作刃，长而凸的外侧切刃缘是工作刃缘，
	1. ==匙形器放入牙周袋时应使工作端的平面与牙根面== ==🔵平行（0°）== ，
	2. 到达袋底后，==与根面间逐渐== ==🔵成 45°==，==以探查根面 [[牙石]] ==，
	3. 探到牙石根方后，==随即与牙面形成== ==🔵约 80° 角== ==进行刮治==。
	4. 在使用过程中只需将工作端露在牙周袋外面的部分与牙齿长轴平行，则其刃缘即与牙根面成 80° 角左右，使刮治技术能较为顺利地进行。==操作完成后，仍回到根面平行的位置（0°），去除器械==。
4. 为避免遗漏所需刮治的牙位，应分区段按牙位逐个刮治，牙石量多或易出血者，可分次进行。
5. 在刮除深牙周袋中的龈下牙石时，应同时将牙周袋内壁的部分肉芽组织刮除。应在局麻下进行，以达到彻底治疗的目的。
6. 刮治后应冲洗袋，检查有无碎片遗留、肉芽组织等，完毕后可轻压袋壁使之贴附牙根面，有利于止血和组织再生修复。

## 超声波龈下刮治

### 龈下机用器械

超声波机本身的类型和工作原理对于龈上和龈下治疗并无区别；其差异在于工作尖的选择不同。
龈下工作尖更为精细，体现在尺寸小且更为细长，便于进入龈下的深牙周袋内进行工作，且在功率选择和手法上也应减少对软组织的损伤。

### 超声波龈下刮治的操作方法

操作方法基本同超声波 [[02Area/Notes/龈上洁治术|龈上洁治术]]，但在去除龈下牙石时，由于肉眼不能直视，而手的感觉又不如手持器械敏感，若操作不当易损伤组织，因而治疗前也应先探明牙周袋深度和形态、根分叉深度或根面的凹陷等情况以及牙石的量和部位等。

### 注意事项

1. 一般的注意事项基本与 [[02Area/Notes/龈上洁治术|龈上洁治术]] 相同；但龈下刮治的工作幅度范围小、功率调控也应更小、操作应更为轻柔，以减少可能的组织损伤和术后不适。
2. 当有急性炎症感染、化脓、重度系统性疾病或全身状况未得到有效控制等情况下，不能进行龈下超声刮治。

## 龈下刮治术和根面平整术后的维护

### 常规维护

每 3~6 个月复查牙周情况，决定是否及何处位点继续重复实施龈下刮治术和根面平整术

### 龈下喷砂维护

1. 龈下喷砂设备维护
2. 龈下喷砂抛光设备维护
3. 注意事项：龈下喷砂需要专用喷嘴，无论是龈上还是龈下喷砂，目的是去除菌斑和色素，均不能去除牙石。
