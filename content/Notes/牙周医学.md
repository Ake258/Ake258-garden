> [!quote] 牙周医学（periodontal medicine）
> 是揭示牙周病与全身健康或疾病的双向关系的一个分支学科。

## 牙周感染对全身疾病的影响

### 口腔病灶感染学说

==🟢病灶（focus）==是指一个局限而具有致病微生物感染的组织，它本身可以表现或不表现症状。
==🟢病灶感染（focal infection）==当病灶内的微生物或其毒性产物向远隔器官或组织转移，引起该远隔器官的疾病或症状时，称为病灶感染。

### 牙周炎与全身疾病和健康的关系

1. 心脑血管疾病：口腔感染引起急性或亚急性 [[感染性心内膜炎]]（endocarditis）是牙周病与全身健康有关的最为明显和肯定的例子。牙周炎与 [[急性心肌梗死]] 和 [[慢性冠心病]] 的关系近年来也得到证实。
2. 糖尿病：牙周病曾被称为 [[糖尿病]] 的 ==第六并发症==，两者的双向关系最为密切。（`双向相关性`）
3. 早产和低出生体重儿
    - 早产＝孕期 ==🔵<37 周==
    - 低出生体重儿＝==🔵<2500 g==
4. 呼吸系统疾病：牙周感染与 [[吸入性肺炎]] 和 [[慢性阻塞性肺疾病]]（COPD）关系密切，在老年患者中尤为明显。
5. 消化系统疾病：牙周袋内可检出 [[幽门螺杆菌]]（Hp）、牙龈出血处检出率更高；牙周袋是 Hp 的贮库，牙周治疗可提高胃 Hp 根除率。
6. 类风湿关节炎：类风湿关节炎和牙周炎都是慢性破坏性炎性疾病，具有许多共同的病理表现，其特征是滑液内和牙周组织内炎症持续浸润和周围硬组织的破坏。
7. 与其他系统疾病的相关关系

### 牙周炎影响全身疾病的可能机制

1. 直接感染
2. 细菌进入血液循环扩散
3. 牙周细菌及其产物引起机体的免疫反应和炎症

## 伴全身疾病患者及特殊人群的牙周治疗

| 疾病              | 情况                                          | 处置                                                                            |
| :-------------- | :------------------------------------------ | :---------------------------------------------------------------------------- |
| 糖尿病             | 对于糖代谢**控制不佳**或有严重并发症的                       | 只进行**应急**的牙周治疗                                                                |
|                 | 对经过积极治疗已控制血糖的                               | 可按常规施以牙周治疗<br>就诊尽量安排在**上午**（早餐及服药后 ==🔵1.5 小时==），尽量控制在 ==🔵2 小时以内==，治疗中观察低血糖。 |
| 心脑血管疾病          | 对于曾在==🔵过去 6 个月内==发生心肌梗死、脑血管意外或处于不稳定性心绞痛状态的 | 只做**应急**处理，不宜过多牙周处理。<br>应在病情稳定 ==🔵6 个月后==再考虑牙周治疗，时间最好避免清早，以近中午为宜。            |
|                 | 对==高血压、冠心病患者==，在服药和病情比较稳定的情况下               | 一些复杂的治疗安排在**下午为宜**                                                            |
|                 | 对风湿性心脏病、先天性心脏病和有人工心脏瓣膜者                     | ==应预防性使用抗生素防感染==，在接受牙周检查或治疗的当天应服药                                             |
|                 | 对心脏起搏器的患者                                   | ==🔴不得使用超声洁牙机==                                                               |
|                 | 高血压                                         | 见下表                                                                           |
| 凝血机制异常患者        | 长期服用抗凝剂者，常有出血倾向                             | 牙周洁治、刮治及手术前，应检查其出、凝血时间和凝血酶原时间                                                 |
| 传染性疾病患者         | 对于活动性传染病                                    | 只在严格防交叉感染的条件下，做应急处理                                                           |
|                 | ==患者不知道或不说自己患有传染性疾病==                       | 临床按==“一致对待”的原则==处理每位患者，防止医院内感染                                                |
| 肿瘤患者            |                                             |                                                                               |
| 妊娠期、备孕期和哺乳期女性患者 |                                             |                                                                               |
| 老年患者            | 卫生状况差、免疫差、唾液少、多伴全身病、用药复杂、自理弱                | 首选控制菌斑、控制炎症、==首选非手术治疗==、==🔴不宜进行过于复杂的治疗==、电动牙刷、间隙刷、定期维护                       |
| 器官移植患者          |                                             |                                                                               |

### 心脑血管疾病——高血压患者的牙周治疗

血压状况对制订牙周治疗计划时的参考

| 高血压   | 情况                                    | 治疗方案                                                                                                                             |
| ----- | ------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 高血压前期 | 收缩压 ==🔵120 mmHg～139 mmHg== 或舒张压 80～89 mmHg | ==牙周治疗同健康人==                                                                                                                     |
| 一期高血压 | 收缩压 ==🔵140～159 mmHg== 或舒张压 90～99 mmHg      | 常规内科咨询，每次就诊时测量血压，告知患者其血压情况，==牙周治疗同健康人==，减小精神压力                                                                                   |
| 二期高血压 | 收缩压 ==🔵＞160 mmHg== 或舒张压＞100 mmHg            | 告知患者血压情况，常规内科咨询，每次就诊时测量血压。如果收缩压＜180 mmHg 和舒张压＜110 mmHg，可进行选择性的牙周治疗（常规检查，预防性洁治，牙周非手术治疗和牙体治疗），减小压力。<br>高血压未治疗的患者==🔴不应给予常规的牙周治疗==。 |
| 三期高血压 | 如果收缩压 ==🔵≥180 mmHg== 或舒张压≥110 mmHg          | 建议立即进行内科治疗，==🔴只进行急症处理==（以减轻疼痛、减少出血和感染），减小精神压力。                                                                                  |
