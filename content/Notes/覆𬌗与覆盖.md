> [!quote]
> ==🟢覆𬌗 (overbite)==：[[牙尖交错𬌗]] 时，上颌牙盖过下颌牙唇（颊）面的**垂直距离**；
> 覆盖 (overjet)：牙尖交错𬌗时，上颌牙盖过下颌牙的**水平距离**。

垂直看覆𬌗，水平看覆盖——前牙的一切𬌗型，都是这两个量偏离正常值后的变形。

## 覆𬌗

前牙（默认）：上颌切牙与下颌切牙切缘之间的垂直距离；后牙：上颌后牙颊尖顶与下颌后牙颊尖顶之间的垂直距离。

**正常覆𬌗**：上颌切牙盖过下颌切牙的垂直距离不超过下颌前牙唇面==🔵切 1/3==；超过者为 [[#深覆𬌗]]。

## 覆盖

前牙（默认）：上颌切牙切缘与下颌切牙切缘之间前后向的水平距离；后牙：上颌后牙颊尖盖至下颌后牙颊尖的颊侧，两牙尖顶之间的水平距离。

**正常覆盖**：前牙水平距离在 ==🔵3 mm== 以内；超过者为 [[#深覆盖]]。

## 深覆𬌗

| 分型 | 位置 |
| ---- | ---- |
| 正常 [[#覆𬌗]] | 上颌切牙盖过下颌切牙牙冠==🔵切 1/3== 以内 |
| Ⅰ° 深覆𬌗 | ==🔵中 1/3== 以内 |
| Ⅱ° 深覆𬌗 | ==🔵颈 1/3== 以内 |
| Ⅲ° 深覆𬌗 | 超过==🔵颈 1/3== |

下颌切牙大部分被上颌切牙包盖，切割食物时下颌向后下滑行距离较大，张、闭口时上颌切牙对下颌切牙限定作用时间较长，对咀嚼肌和颞下颌关节功能有一定影响。

## 深覆盖

| 分型 | 位置 |
| ---- | ---- |
| 正常 [[#覆盖]] | ==🔵3 mm== 以内 |
| Ⅰ° 深覆盖 | ==🔵3~5 mm== |
| Ⅱ° 深覆盖 | ==🔵5~7 mm== |
| Ⅲ° 深覆盖 | ==🔵7 mm== 以上 |

Ⅲ° 深覆盖常造成局部组织损伤，多伴口呼吸；常伴上颌前突面型，对容貌有一定影响。

**深覆盖可伴或不伴深覆𬌗**。

## 对刃𬌗

上、下颌牙切缘接触，覆𬌗、覆盖均为零的前牙咬合关系。对切割功能及面型均有一定程度的影响。

## 开𬌗

上、下颌牙列部分前牙甚至前磨牙在垂直方向上不接触、留有空隙（重者可达尖牙、磨牙之间）。**切割功能完全丧失**，对发育和面型的影响较大。

## 反𬌗

下颌前牙咬在上颌前牙的唇侧，覆盖为负值（" 地包天 "）。该𬌗型基本没有切割功能，对面型、唇齿音的发音等口腔功能都有较大影响。

**后牙反𬌗**：牙尖交错𬌗时，下颌后牙咬在上颌后牙的舌侧（下颌后牙颊尖位于上颌后牙颊尖的颊侧）。

## 锁𬌗与反锁𬌗

- **锁𬌗**：上颌后牙舌尖咬在下颌后牙颊尖的颊侧——上颌完全盖过下颌，将其 " 锁住 "。
- **反锁𬌗**：下颌后牙舌尖咬在上颌后牙颊尖的颊侧——下颌反包上颌。

## 边界

**覆𬌗 vs 覆盖**（最基础的一对）：一垂直、一水平；正常值一个记 "==🔵切 1/3=="、一个记 "==🔵3 mm=="——B 型配伍常把两者互为干扰项。

**深覆𬌗 vs 深覆盖**：分度体系完全不同——覆𬌗按牙冠三等分（切 1/3 → 中 1/3 → 颈 1/3 → 超颈 1/3），覆盖按毫米数（3 / 5 / 7）；两者可伴可不伴。

**程度词考点**（X 型）：切割功能**完全丧失**的只有==🔴开𬌗==；反𬌗是 " 基本没有 " 切割功能；对刃𬌗、深覆𬌗只是 " 一定程度影响 "。

**后牙𬌗型家族**：正常（上颌盖过下颌颊侧少许）→ 锁𬌗（上颌过度盖过）→ 后牙反𬌗（下颌反咬入舌侧）→ 反锁𬌗（下颌过度反包）——按 " 谁包住谁、包到什么程度 " 排一条线记忆。

- ⚠️ 待核实：原《反𬌗》与《反锁𬌗》两篇笔记中 " 后牙反𬌗 " 的定义字面相同（均为 " 下颌后牙舌尖咬在上颌后牙颊尖的颊侧 "），疑为抄录笔误。本篇已按教材通行表述修正（后牙反𬌗=下颌后牙咬在上颌后牙舌侧），请对照人卫八版口解教材核实。
